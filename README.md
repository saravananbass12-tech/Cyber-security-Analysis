## 🚀 Project Overview

The **Cybersecurity Analysis Dashboard** is a Power BI data visualization
project designed to provide an executive-level view of cybersecurity incidents.

The dashboard helps analyze:

- Security incidents
- Financial losses
- Attack vectors
- Incident severity
- Risk trends
- Critical incidents
- Costliest incidents
- Business impact
